Ce programme crée un fichier de rapport "rapport_supershop.txt" sur des données clients présentes dans la base de données ecommerce. Les données sont également affichées dans la console python au lancement du script.

Vous devez : 
- créer un .env dans le répertoire docker avec 

POSTGRES_USER=XXXXX
POSTGRES_PASSWORD=XXXXX

PGADMIN_DEFAULT_EMAIL=XXXXXX
PGADMIN_DEFAULT_PASSWORD=XXXXXXXX

-lancer le projet avec la commande docker compose up -d
